# Results & Evaluation Artifacts

This directory documents the evaluation outputs produced by the project notebook.

The complete experimental workflow is available in:

`notebooks/Military-Civilian-Vehicle-Classification.ipynb`

## Evaluation Areas

### Model Comparison
Compares the custom Baseline CNN against EfficientNet-B0 transfer learning using:

- Test Accuracy
- Macro-F1
- Parameter count
- Inference latency
- Throughput

### Robustness Lab
Evaluates the EfficientNet-B0 model under controlled input perturbations:

- Gaussian noise
- Blur
- Brightness changes
- Contrast changes
- Low-resolution inputs

### Explainability
Includes Grad-CAM analysis to visualize image regions contributing to model predictions.

### Confidence & Error Analysis
Includes:

- Prediction confidence
- Top-K predictions
- Uncertainty estimates
- High-confidence incorrect predictions

### Dataset Forensics
Examines:

- Class distribution
- Train/validation/test composition
- Class imbalance
- Per-class performance

### Embedding Explorer
Uses UMAP to project learned validation embeddings into two dimensions for visual exploration of feature-space structure.

## Reproducibility

These artifacts are generated by the project notebook and can be reproduced by following the documented workflow.

The repository intentionally avoids committing large generated binaries and trained model checkpoints directly into the normal source history.
